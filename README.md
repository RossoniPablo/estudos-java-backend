# Estudos de Java

Repositório de prática e estudo de Java, organizado por pacotes (não por "fase" em pasta solta).

## Estrutura

```
src/java/
├── fundamentos/
│   ├── tiposdedados/         # variáveis, tipos primitivos, wrapper
│   └── estruturascontrole/   # if/else, switch, loops
├── poo/
│   ├── encapsulamento/
│   ├── heranca/
│   ├── interfaces/
│   └── polimorfismo/

```

## Como rodar
Cada classe com `public static void main` pode ser executada direto no IntelliJ
(botão direito no arquivo → Run), sem necessidade de Maven pra esses exercícios simples.
